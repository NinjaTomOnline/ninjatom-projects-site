# NTA-WEB-001 Portfolio Inventory — 2026-07-26

This is the owner-review inventory behind the complete NinjaTom Apps portfolio candidate. It separates **product lifecycle** from **website availability**, uses public-safe names and descriptions, and does not expose private repository URLs, credentials, protected endpoints, or internal machine paths.

## Status model

- **Product status:** shipped, maintained, near release, active development, prototype/concept lab, internal developer tool, planned/on hold, archived/superseded, or excluded.
- **Website status:** public site/storefront, public staging, NinjaTomApps detail route, unavailable, or not applicable.
- Website reachability never proves that a product shipped.
- App Store availability is claimed only for a verified Apple listing.
- Release dates and completion percentages are not inferred from repository metadata or website availability.
